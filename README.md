1. 下载 `BiliPlay_0.9.4_android.apk`。
2. 在手机上允许浏览器或文件管理器「安装未知应用」。
3. 点击 APK 安装；若已安装 0.9.3 或其他同签名版本，可直接覆盖安装。
4. 首次启动需同意用户协议，然后用哔哩哔哩手机客户端扫码登录。
